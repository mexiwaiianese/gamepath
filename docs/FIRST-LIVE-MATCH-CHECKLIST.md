# First Live Match Checklist

## Before the match

- Confirm roster and athlete metadata are complete
- Assign jersey numbers and primary positions if known
- Confirm the starting lineup cards are built
- Check local storage and video path availability
- Validate the app is running locally without Ollama if needed
- Set the opponent, season, and match metadata

## During warmups

- Verify athlete list and lineup assignment
- Ensure the rotation and substitution rules are understood by the recorder
- Confirm video reference recording is active if using local video capture
- Test keyboard shortcuts and the undo flow once before the first set

## During the match

- Record the rally number and score before/after each play
- Add team or athlete event attribution immediately
- Use the quick-entry stat buttons to keep stat speed high
- Correct entries immediately when called out or when the recorder notices a mistake
- Ensure all substitutions and libero replacements are logged
- Capture set end and match end events cleanly

## After the match

- Review player stats and rotation analysis
- Check key metrics for obvious data entry issues
- Export the match to CSV
- Save the match summary and video references
- Review audit history before finalizing the result

## Quality bar

- data is complete and labeled
- correction history is preserved
- calculations match the event log
- no unsupported AI claims are used as source-of-truth stats
- the app remains usable without Ollama
